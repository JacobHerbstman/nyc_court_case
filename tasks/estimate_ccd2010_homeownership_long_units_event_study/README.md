# Estimate 2010 Council-District Housing Event Study

Estimates event-study and long-difference specifications for raw-unit housing
production on 2010 Council district boundaries.

The input is `ccdist2010_homeownership_long_units_series.csv`. Outputs are
`ccdist2010_homeownership_long_units_event_coefficients_raw_units_5yr_bins.csv`,
`ccdist2010_homeownership_long_units_event_coefficients_raw_units_5yr_bins.pdf`,
`ccdist2010_homeownership_long_units_long_difference_raw_units_estimates.csv`,
and `ccdist2010_homeownership_long_units_long_difference_raw_units.tex`.

Runtime: about 2 seconds.
