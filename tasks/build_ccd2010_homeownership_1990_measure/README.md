# Build 2010 Council-District Homeownership Measure

Builds the 1990 homeownership exposure measure on 2010 City Council district
boundaries.

Inputs are the cleaned 1990 NHGIS tract extract, the NHGIS tract GIS zip pointer,
and the archived 2010 Council district boundary file. Creates
`ccdist2010_homeownership_1990_measure.csv` and
`ccdist2010_homeownership_1990_map.pdf`.

Rebuild runtime: about 9 seconds.
