# Summarize Community-District Housing Series

Plots raw MapPLUTO housing production over time by within-borough tercile of
1990 community-district homeownership. A second page ranks Brooklyn's 18
community districts by the same treatment. A third page plots each tercile's
share of its own borough's 5+ and 50+ units, by borough and averaged across
boroughs. New pages go at the end so the paper's page references stay fixed.

Creates `cd_homeownership_long_units_raw_units_plots.pdf` and
`cd_homeownership_historical_decade_units_plot.pdf`.
