# Benchmark ULURP Corpus Universe

Benchmarks the audit-stage ULURP CPC report corpus against external and
upstream universe checks.

The task compares:

- live NYC Open Data ZAP project counts,
- staged ZAP project counts used by the repo,
- the ULURP project/application/CPC report corpus outputs, and
- the existing Council Legistar versus ZAP volume comparison for the
  post-1998 overlap window.

This is not a corpus builder. It is an audit task for deciding whether the
current corpus universe is close enough to promote or needs further recovery.
