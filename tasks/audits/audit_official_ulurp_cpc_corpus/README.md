# Audit Official ULURP CPC Corpus

This task checks the production official-index corpus independently of its
builder. It verifies every local PDF and text artifact, checks whether report
identifiers and standard CPC language appear in extracted text, measures
project-name agreement, identifies exact duplicate content, and draws a stable
100-report-per-decade source-review sample.

The manual columns in the sample remain blank until a source-reading pass is
completed. Automated checks are evidence about file and identifier integrity;
they are not substitutes for substantive document review.

Annual corpus measures use the `Vote Date` published in DCP's CPC Reports
index. Printed report headers and adoption lines sometimes contain stale or
mistyped dates, while the index itself has occasional same-year errors. The
index year is therefore suitable for annual text comparisons, but exact process
duration analysis requires a separate reconciliation to CPC disposition sheets.
