# Summarize ULURP CPC Report Missing Profile

Profiles application/action rows whose CPC reports are verified missing from
the checked public CPC report sources.

The task compares verified-missing rows with successfully text-extracted CPC
report rows by year, decade, action code, application prefix, borough, applicant
type, project status, public status, and broad project-name pattern. It is meant
to show whether the missing 12 percent look random or are concentrated in
particular historical/action categories.
