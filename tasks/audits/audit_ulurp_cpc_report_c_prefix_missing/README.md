# Audit ULURP C-Prefix Missing CPC Reports

Profiles the residual `C`-prefixed ULURP application/action rows whose CPC
reports were not found in the checked public CPC report routes.

This task is meant to separate possible scraper/data-quality concerns from
older or bundled cases where the ZAP project exists but the standard CPC report
PDF route and action-level ZAP CPC report route do not expose a report.
