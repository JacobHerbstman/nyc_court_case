# Official ULURP CPC Event Validation Sample

This audit draws a deterministic 60-narrative sample from the official CPC
text-measurement universe: ten unique analysis narratives per vote decade from
the 1970s through the 2020s.

Within each decade, the sample includes three zoning narratives and three
other-action narratives that contain broad local-actor, stance, and response
language. Four stable-hash comparison narratives are drawn first from reports
that do not meet the broad rule. Only three such reports exist in the 2020s,
so the fourth 2020s comparison is explicitly marked as candidate overlap. The
candidate rule is intentionally permissive and is used only to make the
validation sample informative; it is not a paper measure.

The output preserves the official source URL, local source paths, and exact
source and narrative hashes. Substantive event labels belong in the separate
record-only manual-decision task and are never regenerated here.
