# Citywide ULURP Application Validation

This audit folder stores `code/citywide_ulurp_residential_manual_validation_labels.csv`,
manual labels used to check residential and housing classification rules for
the citywide ULURP application summary.

The labels are not part of the production `summarize_citywide_ulurp_application_trends`
task. They are retained here as a validation record for future classification
checks.
