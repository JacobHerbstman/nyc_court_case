# Citywide ULURP Application Validation

This audit folder stores `code/citywide_ulurp_residential_manual_validation_labels.csv`,
manual labels used to check residential and housing classification rules for
the citywide ULURP application summary.

It also keeps `code/summarize_citywide_ulurp_application_validation.R`, the
broader text-classification script that was removed from the production summary
task. The labels and classification output are validation materials, not inputs
to the production `summarize_citywide_ulurp_application_trends` task.
