# Build Member-Deference Legistar Signals

Screens year-specific Legistar broad-recall pulls for behavior that could
indicate local-member deference being overruled. The first active year is 1998.

This task does not confirm overrules by itself. It links split Council approval
votes to affected Council districts in the matter text and to the member
roster, then labels each matter row as a candidate, rejected screen, or
unresolved roster/geography case for manual audit.
