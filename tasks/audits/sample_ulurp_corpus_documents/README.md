# Sample ULURP Corpus Documents

Downloads a fixed random sample of ULURP source documents for manual reading:
ten projects from the 1990s, ten from 2000-2006, and ten from 2015 onward.

The task uses the all-ULURP spine, queries the public ZAP project API for
document links, prefers application/project-description documents when present,
and falls back to CPC reports when those are the available historical source.
