# ULURP CPC Text Signal Manual Labels

This task preserves researcher-coded decisions used to calibrate the ULURP CPC text-signal audit.

The committed output is `output/manual_ulurp_cpc_text_signal_kwic_labels.csv`. It is intentionally not regenerated by an LLM or script. The file records manual adjudications from KWIC review rounds, including the review id, signal family, application number, binary or unclear label, confidence, and reason.

These labels document judgment calls that shaped the deterministic rules in `tasks/audits/audit_ulurp_cpc_text_signals/code/label_ulurp_cpc_text_signal_kwic.py`. They are calibration evidence, not the full universe of CPC reports.

Run `make` from `code/` to verify that the committed manual-label CSV exists.
