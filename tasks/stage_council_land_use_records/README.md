# Stage Council Land-Use Records

Stages fetched Council-process sources into a normalized matter table. The unit
is a Council project bundle when the official records show multiple LU,
resolution, or ULURP actions moving together.

This task is intentionally conservative: it stages the seed-backed official
records already fetched, keeps source URLs and raw paths attached, and labels
coverage as seed-only until a complete Legistar/archive recall task is added.
