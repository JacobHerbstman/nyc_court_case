# Source Registry

Copies the version-controlled source catalog for the main paper and the
member-deference workflow.

Input: `code/source_catalog.csv`.

Output: `source_catalog.csv`, a stable copy in `output/` for downstream tasks.

The catalog lists public data sources, official web sources, and committed
project-coded ledgers that feed the main results. Audit-only source leads live
under `tasks/audits/` instead.
